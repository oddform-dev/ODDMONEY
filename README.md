## Что такое ODDMONEY?

**ODDMONEY** — лёгкое веб-приложение для планирования личного или семейного бюджета. Введи основной или дополнительный доход, учти обязательные платежи и распредели сумму по собственным категориям. Приложение показывает структуру бюджета, сохраняет историю распределений и помогает следить за накоплениями.

- **Без аккаунта:** регистрация и банковские подключения не нужны.
- **Локально:** настройки и история хранятся в браузере на устройстве.
- **Устанавливается:** работает как PWA на компьютере и смартфоне.
- **Офлайн:** после первой загрузки может открываться без подключения к интернету.

## Последнее обновление интерфейса

- Единые вкладки «Основной доход» и «Дополнительный».
- Светлая и тёмная темы с адаптивным оформлением карточек.
- Компактная мобильная компоновка, адаптивные карточки и статус распределения.
- Компактные строки категорий и колесо выбора процентов от 0 до 100%.
- Цель накоплений с кратким прогрессом, история и статистика сохранённых распределений.
- Диаграмма распределения, история, статистика, цели накоплений и резервное копирование.

## Скриншоты интерфейса

Визуальные варианты приложения подготовлены для двух вкладок и обеих тем:

| Вкладка | Светлая тема | Тёмная тема |
| --- | --- | --- |
| Основной доход | Поля дохода и обязательных платежей, распределение остатка, категории, история | Те же сценарии в тёмном оформлении |
| Дополнительный доход | Независимое распределение дополнительного поступления и собственные категории | Те же сценарии в тёмном оформлении |

В приложении используются актуальные названия «Основной доход» и «Дополнительный». Скриншоты отражают текущую структуру интерфейса, а не старые сценарии «зарплата» и «аванс».

## Возможности

| Раздел | Что умеет |
| --- | --- |
| **Основной доход** | Учёт поступления, обязательных платежей и суммы, оставшейся для распределения |
| **Дополнительный доход** | Отдельное распределение дополнительного поступления со своими категориями и процентами |
| **Категории** | Добавление, удаление и переименование; настройка долей с помощью колеса процентов от 0 до 100% и проверка общей суммы в 100% |
| **Визуализация** | Круговая диаграмма и наглядная разбивка по категориям |
| **История** | Сохранение расчётов, просмотр прошлых распределений и копирование плана |
| **Накопления** | Финансовая цель и отслеживание прогресса |
| **Статистика** | Сводка по сохранённым выплатам и итогам за текущий месяц |
| **Резервная копия** | Экспорт и импорт настроек, категорий, цели и истории в JSON |
| **Экспорт** | Выгрузка истории расчётов в CSV |
| **Темы** | Переключение светлого и тёмного оформления |

## Как начать

1. Открой **[ODDMONEY](https://oddform-dev.github.io/ODDMONEY/)**.
2. Выбери вкладку **«Основной доход»** или **«Дополнительный»**.
3. Введи сумму дохода; для основного дохода укажи обязательные платежи, если они есть.
4. Настрой категории и проценты распределения. На телефоне нажми на процент, чтобы открыть колесо выбора.
5. Сохрани результат, скопируй план или экспортируй историю.

### Установка на устройство

- **Компьютер:** открой сайт в поддерживаемом браузере и нажми значок установки в адресной строке, если он доступен.
- **iPhone / iPad:** открой сайт в Safari → «Поделиться» → «На экран Домой».
- **Android:** открой сайт и выбери «Установить приложение» или «Добавить на главный экран».

## Приватность и хранение данных

ODDMONEY не подключается к банкам и не отправляет ваши бюджетные данные на собственный сервер. Расчёты, настройки и история хранятся в локальном хранилище браузера на текущем устройстве.

**Важно:** данные не синхронизируются автоматически между устройствами. Очистка данных сайта или браузера может удалить сохранённую историю. Для переноса данных или дополнительной страховки используй раздел резервного копирования и экспорт в JSON.

## Запуск локально

Это статическое приложение на HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются.

```bash
git clone https://github.com/oddform-dev/ODDMONEY.git
cd ODDMONEY
python -m http.server 8000
```

Затем открой http://localhost:8000. Локальный HTTP-сервер удобнее, чем открытие `index.html` напрямую, потому что позволяет проверить Service Worker и PWA-функции.

## Технологии

- HTML, CSS и JavaScript без сборщика и сторонних фреймворков.
- Web App Manifest и Service Worker для PWA и офлайн-кэша.
- `localStorage` для хранения пользовательских данных на устройстве.
- GitHub Pages для публикации.
