## Что это?

**«Куда бабки?»** — небольшой калькулятор семейного бюджета. Введи сумму выплаты, учти обязательные платежи и распредели остаток по своим финансовым категориям. Никаких аккаунтов, серверной базы или установки тяжёлого приложения.

Приложение работает в браузере, поддерживает установку как **PWA** и может открываться офлайн после первой загрузки.

## Возможности

### 💰 Основная зарплата
- Учёт полученной зарплаты.
- Вычитание кредита, доплаты по ипотеке и других обязательных расходов.
- Распределение остатка по семи категориям.
- Настройка процентов с проверкой суммы на 100%.
- История сохранённых распределений.
- Копирование плана и экспорт истории в CSV.

### 🪙 Аванс
- Отдельный ввод фактически полученного аванса.
- Независимые проценты распределения по четырём категориям.
- Отдельная история авансов и копирование плана.
- Авансовая схема не включает кредит, ипотеку, счёт дочери, ремонт и большие траты.

### 📱 Просто и приватно
- Установка на компьютер или телефон как приложение PWA.
- Поддержка офлайн-режима после первой загрузки.
- Данные хранятся локально в браузере на текущем устройстве.
- Не нужны регистрация, аккаунт или подключение к финансовым сервисам.

## Распределение по умолчанию

### Основная зарплата

| Категория | Доля |
| --- | ---: |
| Общий счёт | 30% |
| Мой счёт | 17% |
| Счёт жены | 17% |
| Счёт дочери | 5% |
| Фонд ремонта | 14% |
| Большие траты | 14% |
| Фонд особых случаев | 3% |

Проценты считаются от остатка после вычета обязательных платежей.

### Аванс

| Категория | Доля |
| --- | ---: |
| Общий счёт | 45% |
| Мой счёт | 20% |
| Счёт жены | 20% |
| Фонд особых случаев | 15% |
| **Итого** | **100%** |

Это стартовые значения. Их можно изменить в интерфейсе.

## Как пользоваться

1. Откройте **[Куда бабки?](https://anrbnk.github.io/kuda-babki/)**.
2. Выберите вкладку «Основная зарплата» или «Аванс».
3. Введите сумму выплаты и, для основной зарплаты, обязательные расходы.
4. При необходимости измените проценты распределения.
5. Сохраните расчёт, скопируйте план или экспортируйте историю.

### Установка как приложения

**На компьютере:** откройте сайт в поддерживаемом браузере и используйте значок установки в адресной строке, если он доступен.

**На iPhone или iPad:** откройте сайт в Safari, нажмите «Поделиться» и выберите «На экран Домой».

**На Android:** откройте сайт в браузере и выберите «Установить приложение» или «Добавить на главный экран», если этот пункт доступен.

## Запуск локально

Это статическое веб-приложение: отдельный сервер, сборка и менеджер пакетов не нужны.

1. Скачайте репозиторий или клонируйте его:
   ```bash
   git clone https://github.com/anrbnk/kuda-babki.git
   cd kuda-babki
   ```
2. Откройте `index.html` в браузере для базовой проверки.

Для полноценной проверки PWA и service worker запускайте файлы через локальный HTTP-сервер или GitHub Pages. Например, если установлен Python:
```bash
python -m http.server 8000
```
Затем откройте http://localhost:8000.

## Хранение данных и ограничения

- Расчёты и история сохраняются в `localStorage` браузера на текущем устройстве.
- Данные не синхронизируются автоматически между устройствами и браузерами.
- Очистка данных сайта или хранилища браузера может удалить сохранённую историю. При необходимости регулярно экспортируйте CSV.
- Приложение помогает планировать бюджет, но не подключается к банкам и не проверяет реальные транзакции.
- Офлайн-работа зависит от того, была ли страница загружена и установлен ли service worker.

## Технологии

- HTML, CSS и JavaScript без сборщика.
- Web App Manifest и Service Worker для PWA.
- `localStorage` для локального хранения.
- GitHub Pages для публикации.
